# Contributing

Small, reviewable, original work only. See docs/LEGAL-LICENSE.md + docs/DEVELOPMENT.md.

- Inspect before modifying; smallest safe diff; reuse abstractions.
- No copied proprietary code/assets/offsets/branding.
- One concern per commit; branches: `feature/*`, `fix/*`, `research/*`.
- Every feature: impl + tests + compat check + docs + CHANGELOG entry.
- Never commit secrets, `.env`, game binaries, or local DBs.
